## How to regenerate & expectations

```bash
# One command — throughput + real traced breakdown + fine-grained signposts:
QWEN36_LAYERS=40 ./python_env/bin/python \
    models/demos/qwen3_6_a3b/tests/gen_current_benchmark.py \
    --breakdown-layers 4 --seq 128 --gen 32
```

**What to expect when running it**
- **Runtime ~10–15 min**: one 40-layer model load (~110 s warm from the `.tensorbin` cache, longer cold) drives both §1 and §2; a second, small-layer load drives the §3 profiled run. Model-load time is excluded from all reported figures.
- **Two device sub-runs** (see `$TMPDIR/qwen36_throughput.log` and `qwen36_breakdown.log`). The script itself never opens the device.
- **§3 is profiled at 4 layers on purpose.** The tt-metal device profiler aborts during device-data readback above ~4–8 layers (buffer overflow at scale), so a full 40-layer signpost capture is currently not possible. Per-layer op shapes are identical at any depth, so the *proportions* in §3 hold for 40 layers; the real 40-layer per-component ms are in §2 (which uses un-profiled wall-clock replays and is stable at 40).
- **Trust ratios, not absolutes, in §3** (profiler inflates ~1.8×). §1 and §2 are real wall-clock.
- **When numbers move**: re-run after any change to kernels, dtypes (`tt/model_config.py`), layer config, or the tt-metal/ttnn version. Decode tok/s/user is the headline single-user metric; watch the §2 component that dominates (today: MoE).

**Piecewise / deeper profiling**
```bash
# throughput + real traced breakdown only (40 layers):
QWEN36_LAYERS=40 ./python_env/bin/python models/demos/qwen3_6_a3b/tests/benchmark.py --gen 32
# fine-grained signposts only (keep layers small — see the §3 profiler-scale note;
# and NO -p flag: it truncates the capture), then slice each window:
QWEN36_LAYERS=4 QWEN36_SIGNPOST=1 QWEN36_SEQ=128 QWEN36_PROF_EAGER_ONLY=1 \
    ./python_env/bin/python -m tracy -r -v --op-support-count 20000 \
    models/demos/qwen3_6_a3b/tests/prof_decode.py
python models/demos/qwen3_6_a3b/tests/signpost_report.py --between eager_start eager_stop
python models/demos/qwen3_6_a3b/tests/signpost_report.py --between prefill_start prefill_stop
```

Signpost regions are documented in `DEBUGGING.md` §1.5.1; markers are env-gated (`QWEN36_SIGNPOST`) and cost nothing in normal runs.
