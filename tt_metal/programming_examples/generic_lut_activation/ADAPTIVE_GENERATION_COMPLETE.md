## Binary Format Verification

Both uniform and adaptive LUTs now use the same format with boundaries:

```
[uint32 num_values]
[float boundaries[num_segments + 1]]
[float coefficients[...]]
```

### Example: Linear exp depth=16

**Uniform boundaries** (evenly spaced by 0.625):
```
-5.000, -4.375, -3.750, -3.125, -2.500, -1.875, -1.250, -0.625,
 0.000,  0.625,  1.250,  1.875,  2.500,  3.125,  3.750,  4.375, 5.000
```

**Adaptive boundaries** (denser where curvature is high):
```
-5.000, -4.059, -3.118, -2.177, -1.236, -0.295,  0.646,  1.577,
 2.487,  3.298,  3.879,  4.249,  4.490,  4.670,  4.800,  4.910, 5.000
```

**Observation**: Segments progressively smaller toward x=5 (exponential growth region)

## Generation Method

### 1. Adaptive Breakpoints (from CSV)

Breakpoints loaded from `adaptive_segments/depth_{4,8,16,32}_segments.csv`:
- Generated by curvature analysis (|f''(x)| weighting)
- Include hardcoded critical points (discontinuities, inflections)
- Different for each activation based on function characteristics

### 2. Coefficient Fitting (Proper Method)

**CORRECT** (what we did):
```python
adaptive_breakpoints = load_from_csv(activation, depth)
coeffs = fit_polynomial(func, adaptive_breakpoints)  # NEW fit!
write_lut(coeffs, adaptive_breakpoints)
```

**WRONG** (old approach):
```python
uniform_coeffs = fit_polynomial(func, uniform_breakpoints)
evaluate_with_adaptive_lookup(uniform_coeffs, adaptive_breakpoints)  # MISMATCH!
```

### 3. Parallel Generation

- 29 activations processed in parallel
- Each process generates 5 polynomial types × 4 depths = 20 LUTs
- Generation completed in ~2 minutes on local machine
